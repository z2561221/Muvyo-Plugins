# 未来道具研究所 · Muvyo 插件

本仓库用于分发加密并签名的 Muvyo 第三方插件产物。

| 插件 | ID | 版本 | 最低 Muvyo |
|---|---|---|---|
| 克里斯蒂娜 · Kurisu | z2561221.kurisu-mascot | 1.0.2 | 3.11.1 |

在 Muvyo「第三方插件 → 插件仓库」添加本仓库地址，安装并启用后，
在「慕慕 AI 助手 → 慕慕形象」选择“克里斯蒂娜 · Kurisu”。

插件替换助手名称与立绘，不申请联网权限。当前 1.0.2 为两帧兼容版：
提供待机、挥手两张透明立绘。挥手第二帧与完成动作回退到挥手，其余缺失动作回退到待机，
遵循 Muvyo 官方的动作回退规则。助手能力和对话方式保持原样。

在 Muvyo 3.11.1-1 上，隔离对照实验显示 4 个签名内容文件可通过原生校验，
5 个及以上的测试包被拒绝，因此当前包保留清单、加密入口、两张立绘共 4 个签名内容文件。
14 帧完整版保留在历史版本 1.0.0 / 1.0.1 中，当前宿主无法安装这两个版本。

仓库仅包含安装所需的签名文件、加密入口、清单、图片和说明，
不包含本地源码、作者签名私钥或仓库索引私钥。
