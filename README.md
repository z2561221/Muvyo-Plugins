# 未来道具研究所 · Muvyo 插件

本仓库用于分发加密并签名的 Muvyo 第三方形象插件。

| 插件 | ID | 版本 | 最低 Muvyo |
|---|---|---|---|
| 克里斯蒂娜 | z2561221.kurisu-mascot | 1.0.4 | 3.11.1 |
| 洛琪希 | z2561221.roxy-mascot | 1.0.0 | 3.11.2 |

克里斯蒂娜：牧濑红莉栖，天才神经科学少女，未来道具研究所成员。理性敏锐、嘴硬心软，陪你探索世界线。

洛琪希：蓝发双辫的米格路德族魔法师。温柔认真、博学可靠，陪你学习与探索。

两款插件均提供 14 个静态动作槽位，不申请联网或内部服务权限。
洛琪希 1.0.0 保留正常动漫比例，提供待机、眨眼、说话、注视、挥手、指向、吃爆米花、点赞、跳起、蹲下和坐姿微笑。
素材为透明 WebP，针对当前桌面聊天框保留顶部空间；实际动作切换与运动由 Muvyo 控制。

在 Muvyo“第三方插件 → 插件仓库”添加本仓库地址，安装并启用后，
在“慕慕 AI 助手 → 慕慕形象”选择所需人物。
洛琪希已通过官方素材与签名工具检查；实际宿主和页面验收以安装后的检查为准。

分支、PR 门禁、验收与 Release 采用 MoviePilot 插件仓库同款流程，见 [发布流程](RELEASE-WORKFLOW.md)。

仓库包含签名安装产物、流程说明和必要 CI 工具，不包含人物源代码、原始视频、生图配置或签名私钥。
