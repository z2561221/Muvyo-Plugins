# 克里斯蒂娜 · Kurisu

适用于 Muvyo 3.11.1 及以上版本的 mascot 形象插件。作者显示名 Kurisu，命名空间 z2561221。
替换悬浮立绘、对话框头像、界面名称和 AI 自称；助手能力、权限与对话方式不变。
请从签名插件仓库安装，源码目录不能直接导入。

签名发布并安装启用后，在「设置中心 → 插件 → 慕慕 AI 助手 → 慕慕形象」选择本插件。
14 个槽位均来自既有 Kurisu 原图；爆米花、点赞、蹲下、坐姿使用相近姿势。
每张图片为 320×480 透明静态 WebP，使用相同比例、脚底对齐。
本插件不包含 Codex Pet 行为引擎。动作触发、切换和位移由 Muvyo 控制。

迁移旧版 CSS 换肤时，先备份自定义 CSS，再仅移除带 MUVYO KURISU CODEX PET SKIN 标记的旧区块，
保留其余 CSS。停用或移除插件后，Muvyo 会恢复官方慕慕。
